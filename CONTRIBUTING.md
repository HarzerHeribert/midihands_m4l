# Contributing

Thanks for your interest in MidiHands.

- **Bugs and ideas:** open an issue. Include your macOS version, Live version, camera,
  and what you expected versus what happened.
- **Pull requests:** welcome as suggestions, but the project owner decides what goes in and
  may close a pull request without merging it, or rewrite the change. Only the owner merges.
- **Rights:** the code is not open source (see [LICENSE](LICENSE)). By opening a pull request
  you agree that the project owner may use, change and relicense your contribution under
  any terms, including commercially, without obligation to you.
- **Security problems:** please don't open a public issue; see [SECURITY.md](SECURITY.md).
